# Антиспам для комментариев канала «За гранью»

Комментарии канала на самом деле живут в привязанной группе обсуждений. Бот сидит там админом и проверяет каждое сообщение.

## Что делает
- Считает баллы: ключевые фразы (работа и заработок, «пиши в лс», «скачай/забирай», крипта, 18+), латиница внутри русских слов («рабoта»), ссылки и инвайты, @упоминания, кнопки под сообщением, пересылки, комменты от имени чужого канала, спам в имени профиля, первое сообщение, база спамеров CAS.
- От 5 баллов удаляет сообщение, банит автора и стирает все его сообщения в группе. Вам приходит отчёт с кнопкой «Разбанить».
- 3–4 балла: сообщение остаётся, вам приходит отчёт с кнопками «Забанить» / «Не спам».
- После 3 чистых комментариев человек становится доверенным, и бот его больше не проверяет.
- Правка сообщения тоже проверяется: спамеры часто пишут сначала безобидный текст, а потом меняют его.

## Запуск
1. В @BotFather: `/newbot`, получить токен.
2. Узнать свой id, например через @userinfobot.
3. Канал → Обсуждение → группа → Администраторы → добавить бота. Права: **удаление сообщений** и **блокировка пользователей**.
   Бота стоит добавить админом и в сам канал (достаточно без прав). Тогда он найдёт группу обсуждения сам.
4. Написать боту `/start` в личку, иначе он не сможет присылать отчёты.
5. Установка и запуск:
   ```
   pip install -r requirements.txt
   copy .env.example .env      # заполнить BOT_TOKEN и OWNER_ID
   python bot.py
   ```
6. Первые пару дней держать `DRY_RUN=1`, смотреть отчёты «был бы бан», потом `/mode live` или `DRY_RUN=0`.

Боту нужно работать круглосуточно. Рабочий ноутбук для этого не подходит, лучше дешёвый VPS за 150–300 ₽/мес (оценка, не прайс) или Raspberry Pi дома. На Linux: `systemd`-сервис или `tmux`.

## Команды (в личке с ботом, только владелец)
`/stats`, `/mode test|live`, `/words`, `/addword фраза`, `/delword фраза`, `/unban id`, `/trust id`.
В группе админ отвечает `/spam` на сообщение: удалить и забанить. `/chatid` показывает id группы.

## Встроенная защита Telegram (включить в дополнение)
- Группа обсуждения → Разрешения → «Сначала вступить в группу» (Join to send). Отсекает часть одноразовых ботов.
- Администраторы → «Агрессивный антиспам». Доступен в группах от ~200 участников.
- Разрешения → запретить ссылки/медиа для новичков (медленный режим по желанию).
